# LifeAtlas

## 项目简介

LifeAtlas 是一款围绕个人生活记录、穿搭管理和 AI 辅助分析设计的生活管理 App。

本文件只记录项目整体情况。详细产品需求统一维护在 `REQUIREMENTS.md` 中。

## 当前版本

- 版本号：`2.3.3`
- 构建号：`34`
- 当前阶段：穿搭板块完整品类参数、Doubao 图片识别、预购文字分析、Cloudflare Workers HTTPS 代理及单账号短期令牌认证已接入；真实天气及今明逐小时预报已接入；其他 AI 功能及系统后台唤醒待后续接入

## 项目目标

- 建立统一的个人生活记录入口，关联天气、日历、文字、图片和每日穿搭。
- 管理衣物、套装、穿搭记录、预购衣物和个人身材数据。
- 基于天气、历史穿着数据和用户身材提供 AI 辅助分析与穿搭建议。
- 支持用户按需开启或关闭功能板块，并在关闭时保留已有数据。
- 保持清晰的需求、版本和开发规则记录。
- 以小范围、可验证、可回溯的方式持续迭代。

## 护肤模块（2.0.0）

从我的－板块管理启用。建立档案和目标，搜索或拍摄产品并确认资料版本，生成规则/AI计划，预览确认后逐步执行。SQLite v12 保留旧数据，历史步骤保存快照。产品库为独立 JSON 版本包，目前精选 4 款美国官网资料，未收录产品可先记录名称。

护肤 AI 需部署 `tooling/cloudflare_worker` 新增接口，复用既有安全登录；没有部署时可使用本地规则方案。客户端不包含供应商密钥。Android 提醒为非精确定时，未来 28 天滚动安排，每次进入/恢复更新；iOS 通知尚未实现。

条码补充查询采用 Open Beauty Facts 公共接口，由用户主动触发，仅发送条码；社区数据保留来源及 ODbL 标识，不视为已核实产品资料。

## 2.3.1 天气调整

天气与城市页保留简洁官网归因，底部左侧获取时间、右侧独立刷新；下方显示按城市时区分组的今天/明天小时预报。首页不显示获取时间。代理扩展为 `weatherHourly`，通过和风 `/weather/v1/hourly/{latitude}/{longitude}?hours=72` 获取数据；需配套后台版本，未开通小时服务时明确提示错误，保留当前天气。城市缓存15分钟，手动刷新绕过缓存。
