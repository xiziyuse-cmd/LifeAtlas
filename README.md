# LifeAtlas

## 项目简介

LifeAtlas 是一款围绕个人生活记录、穿搭管理和 AI 辅助分析设计的生活管理 App。

本文件只记录项目整体情况。详细产品需求统一维护在 `REQUIREMENTS.md` 中。

## 当前版本

- 版本号：`1.0.0`
- 构建号：`1`
- 当前阶段：第一阶段基础框架已完成，天气、日历和穿搭详细业务待后续迭代

## 技术栈

- Flutter（Stable）
- Dart `^3.12.2`
- Material Design
- SQLite（`sqflite ^2.4.3`）
- `flutter_test`
- `flutter_lints ^6.0.0`
- 当前已初始化平台：Android、iOS

## 项目目标

- 建立统一的个人生活记录入口，关联天气、日历、文字、图片和每日穿搭。
- 管理衣物、套装、穿搭记录、预购衣物和个人身材数据。
- 基于天气、历史穿着数据和用户身材提供 AI 辅助分析与穿搭建议。
- 支持用户按需开启或关闭功能板块，并在关闭时保留已有数据。
- 保持清晰的需求、版本和开发规则记录。
- 以小范围、可验证、可回溯的方式持续迭代。

## 项目目录说明

```text
lifeatlas/
├─ android/                 Android 平台工程
├─ ios/                     iOS 平台工程
├─ lib/                     Dart 与 Flutter 业务代码
│  ├─ app/                  应用根组件与全局状态控制
│  ├─ core/                 数据库、设置与主题基础设施
│  ├─ features/             首页、板块、我的、天气、日历与穿搭模块
│  ├─ shared/               跨模块复用组件
│  └─ main.dart             应用入口
├─ test/                    模型与界面测试
├─ analysis_options.yaml    Dart 静态分析与代码规范配置
├─ pubspec.yaml             项目版本、依赖与资源配置
├─ README.md                项目总体介绍
├─ CHANGELOG.md             版本更新记录
├─ REQUIREMENTS.md          全部需求说明与需求历史
└─ CODEX_RULES.md           Codex/AI 开发规则
```

`.dart_tool/`、平台生成文件和 IDE 配置属于工具生成或本地环境内容，不作为业务模块说明。
